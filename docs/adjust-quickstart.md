# KoAdjust SOP

KoAdjust is a topology-preserving sculpting workbench. It records an ordered brush history inside one Houdini asset (`ko::koadjust::1.0`). Move, Clay, Inflate, Smooth, Relax, and Planar edit point positions; they never add, remove, split, or reconnect components. Extrude, Inset, Bevel, and Fill are intentionally outside KoAdjust.

## In the viewport

1. Restart Houdini with Ko on `HOUDINI_PATH`. In a Geometry object with a polygon mesh displayed, select **KoAdjust** as the Scene View radial. **C** opens the active radial in the Ko keymap. You can also wire the **KoAdjust** SOP manually and enter its node state. Switching brushes reuses the displayed KoAdjust.
2. **Move** (the grab brush) defaults to the view plane, as in Sculpt 2.0. While **Move** is selected, press **Ctrl+Alt+M** to toggle between **View Plane** and **Surface Normal** before a stroke. **Move Direction** is shown only for Move. Use vertical drag if the normal is viewed end-on. **Clay** builds a rounded mound around a plane anchored at the pick; **Inflate** moves along local normals. Hold **Ctrl** to invert Clay or Inflate. **Smooth** averages neighboring positions, **Relax** redistributes them tangentially, and **Planar** moves them toward the fixed plane at the stroke anchor, following Sculpt 2.0’s naming. Hold **Shift** before pressing LMB to use Smooth for just that gesture. Click for one dab or drag across the surface to paint a stroke. KoAdjust stores spaced surface samples and replays them as one edit. New strokes use one shared distance solve and the nearest stamp’s falloff, rather than simulating sequential Sculpt 2.0 stamps. Existing strokes keep their recorded blending behavior. Move still follows the first hit. Smooth uses a wider neighborhood for new strokes. Scroll or **Ctrl+Shift+LMB drag** resizes the brush. **Ctrl+Shift+MMB** horizontally adjusts Strength and vertically adjusts Falloff. The HUD uses Houdini’s mouse glyphs and short labels. The outer ring is the radius, the inner ring is the 50% falloff contour, and its line width shows strength. The prompt shows numbers while adjusting. Esc cancels.
3. During a gesture, the shaded result stays live. The before wireframe is faint, and visible parts outside the current brush footprint are ghosted. Use **RMB → Affect** to set where the brush can spread. A reviewed stroke's mode can also be changed.
4. Open **Parts → Open Parts List** in the KoAdjust parameters, or add a **KoAdjust Parts** pane tab to your desktop. The list follows the linked KoAdjust node and shows one eye per part, without network controls or a tab bar while the list is active. Filter by name, use **Show All** to clear the visibility mask, or select a row and press Space to toggle it. The brush target is bold. **RMB → Parts** still offers hide or isolate by clicking. Hidden parts are excluded from picking, **not** from deformation in Nearby or Connected mode. Visibility doesn't change topology, rendering, or saved stroke intent. With **Apply Part Visibility to Output** off, hiding only applies while the KoAdjust viewer state is active. Turn it on to carry the visibility mask downstream after you leave the tool. Part classification changes reset obsolete visibility choices on the next pick or resume.
5. **Rewind To** lists the newest strokes first and displays the last stroke’s name when set to Latest. It cooks and shows the result through the chosen stroke, or the input at **Before All Strokes**. If you start brushing from an earlier stroke, click **Continue** in the confirmation and then brush again. The dialog takes focus, so the press that opened it is not a stroke. KoAdjust remembers the confirmation at that rewind point; canceled or failed strokes keep the later edits. A successful stroke replaces them, and one undo restores the discarded history. Choose **Latest** to return without editing. RMB **Stroke History** offers previous/next, a native Move gizmo, mute, and rebind. The internal `deform` SOP retains brush amount and `bind` retains radius. Houdini saves the stack in the scene; existing strokes cook without the Python viewer UI.

## Parts and influence

**Define Parts By** supports:
- **Connectivity:** a part per connected polygon component (default).
- **Primitive Attribute:** use a scalar string/integer primitive attribute, for example `name`, `part`, or a class attribute. Equal values label the same part; attribute values are also saved as anchor evidence. Use stable, intentional labels rather than regenerated element numbers.
- **UV Islands:** use the named **vertex** UV attribute (default `uv`); UV seams separate parts without cutting the mesh. Matching UVs only join across a shared mesh edge, so stacked UV islands stay separate.

| Affect mode | What moves |
|---|---|
| **One Part** | A radius-limited connected patch inside the picked part. Vertices shared with a different part are pinned, so strict isolation doesn't require splitting seams. |
| **Nearby in 3D** | Points within the brush sphere, including separate nearby shells. This intentionally can reach through thin surfaces. |
| **Topologically Connected** | A radius-limited patch reached along mesh edges from the picked surface. It can cross part labels or UV seams, but cannot jump to a separate nearby shell. |

No mode moves an entire part outside the brush radius. While dragging, the brush prefers the part where the stroke began, even when it passes behind another part. If the target is fully obscured at the start, hide the foreground part to pick it. Changing an existing stroke's influence updates its replay; visibility is independent of that choice.

## Replay and repair

For KoAdjust scenes made before this update, entering the viewer state updates the saved brush kernels in place. You can also press **Migrate Old Brush Data** on the SOP. This keeps the authored anchors, radius, and stroke amounts.

A stroke stores its surface anchors and normals, part-definition evidence, radius and falloff, and displacement or strength—not vertex numbers or a geometry stash. On an upstream change, KoAdjust reprojects the anchor along its normal and builds a new local influence field. Automatic part numbers are for display only; the stroke resolves its part from the current hit. Projection ranks candidates by offset and normal agreement, favoring an authored attribute label when one is available. A nearby second shell no longer causes a warning by itself. A genuinely tied surface is only accepted if the selected mode makes the answer equivalent (such as coincident hits in Nearby in 3D), or if the candidates are the same surface at a shared seam. Otherwise, a missing or tied surface, renamed attribute part, or changed part definition skips the edit and raises a warning. Choose that edit and **RMB → Stroke History → Rebind Reviewed Stroke**, then click a new anchor. Large poses still need manual repair; this is not an articulated landmark system.

The local bind and deform cook are separate. Dragging strength/translation doesn't re-run the radius/anchor resolver; changing radius or upstream geometry does. The default local edge-distance falloff is bounded and approximate on coarse mesh. The design draws on Houdini [Stroke](https://www.sidefx.com/docs/houdini/nodes/sop/stroke.html) and [Stroke Cache](https://www.sidefx.com/docs/houdini/nodes/sop/strokecache.html), but keeps each stroke's binding editable instead of saving per-point results or an entire mesh. [Heat Geodesic](https://www.sidefx.com/docs/houdini/nodes/sop/heatgeodesic.html) is an option to evaluate if edge-distance artifacts matter, not a dependency for local strokes. Python is used for viewer input, native handles and SOP authoring only.

## Checks and rebuild

Checked on Houdini **22.0.466**. Run `hython tests/ko/adjust_houdini_smoke.py` for topology, all six brushes, nearby/tied surface resolution, named/connectivity/UV part modes, rewind, hide-mask invariance, and save/reopen. Run `scripts/modeling_gui_test.ps1` for hidden-desktop callback checks (including picking through a hidden part, undo, and rebind). Rebuild with `hython scripts/build_adjust_hda.py`. The intermediate Adjust preview asset is superseded; its scenes aren't converted automatically.

For a cook-only performance check, run `hython tests/ko/adjust_perf.py`. On the 25,600-point fixture with roughly 60 samples, the median Smooth recook dropped from about 208 ms to 15 ms. This does not include viewport draw time.
